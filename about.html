About Axiom Renovations

A company built on Axioms

The name Axiom points to the standards that guide each project: create real value, be honest about the work, solve problems correctly, and keep the experience as steady as possible for the homeowner.
Axiom 1
Value comes first
The work should improve the home in a way the customer can see, use and appreciate.
Axiom 2
Truth is self-supporting
Work built on honesty and clarity is akin to a sculptor removing the stone until the image is revealed.
Axiom 3
Correct work simplifies everything
Everything is easy when it is done correctly. It is worth the time to find the correct approach for each unique situation.
Axiom 4
Good work should feel good
When the process is enjoyable and everyone is at ease, the result improves.
